# Competitive Analysis: LigoBot (LIGO)

## 📊 Executive Summary

**LigoBot** (operated by LIGO CORP) is a LINE translation bot that serves as the primary competitor in the LINE translation bot market. This document provides a comprehensive analysis of LigoBot's features, pricing, user experience, and market positioning to inform our competitive strategy for @LanguageBridgeBot.

**Website:** https://www.ligobot.com/  
**LINE Bot ID:** @LIGO  
**Company:** LIGO CORP  
**Status:** Active (© 2025)

## 🎯 Core Features

### 1. Language Support
- **100+ languages** supported
- Key languages mentioned: English, Chinese (Simplified & Traditional), Thai, Japanese, Spanish, French, Italian, German, Korean, Vietnamese, Turkish, Portuguese, Indonesian, Hindi, Punjabi, Bengali, Russian, Serbian, Arabic, Polish, Greek
- Multi-language translation (MLT) capability

### 2. Translation Features

#### **Multi-Language Translation (MLT)**
- Translate messages into multiple languages simultaneously
- Supports 2-5 languages per group configuration
- Uses language codes (e.g., `en`, `th`, `hi`)

#### **Ignored Word Feature**
- Users can specify words/phrases that should NOT be translated
- Useful for names, acronyms, abbreviations
- Prevents translation of specific terms

#### **Color Box Style**
- Visual formatting option for translated messages
- Enhances readability in group chats

#### **Translation Accuracy Improvements**
- Provides guidance on improving translation accuracy
- Users can optimize their messages for better results

### 3. User Controls

#### **Per-User Translation Toggle**
- `#on` command: Enable translation for yourself
- `#off` command: Disable translation for yourself
- Individual control within group settings

#### **Profile Picture Display**
- User profile pictures appear in translated messages
- Requires adding Ligo as a friend (not just group member)

## 🚀 User Experience & Setup

### Setup Process

1. **Add Friend**
   - Search LINE by ID: `@LIGO`
   - Add as friend
   - Or use "Add Friend" button on website

2. **Configure Languages**
   - Command: `#set [lang1] [lang2] ... [lang5]`
   - Minimum: 2 languages
   - Maximum: 5 languages
   - Example: `#set en th` (English and Thai)
   - Must be sent in the group chat

3. **Start Using**
   - Messages automatically translate based on configured languages
   - Translations appear as replies in the group

### Command Structure
- Uses `#` prefix for commands (not `/`)
- Commands:
  - `#set [lang codes]` - Configure languages
  - `#on` - Enable translation for user
  - `#off` - Disable translation for user
